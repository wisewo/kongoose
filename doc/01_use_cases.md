# Use Cases

## Notes

- Use Case는 플레이어가 게임 시스템과 상호작용하여 달성하는 목표만 포함한다.
- Use Case는 플레이어가 명시적으로 수행하는 버튼 클릭, 키 입력, 프로그램 실행 같은 행위를 기준으로 식별한다.
- 과제 제출물, 보고서, 발표 준비 등은 소프트웨어 시스템의 Use Case가 아니므로 제외한다.
- 게임 루프의 시간 흐름, 장애물 이동, 사운드 재생, 상태 표시, 리소스 표시는 독립 Use Case로 두지 않고 관련 Use Case의 시스템 반응 또는 요구사항으로 다룬다.
- 진행 데이터 저장/불러오기는 독립 Use Case로 두지 않고, 메인 화면 진입 및 스테이지 클리어 흐름에 통합한다.
- Priority는 `Must`, `Should`, `Could`, `Hold`로 표기한다.

## Scope Adjustments

| 항목 | 처리 |
|---|---|
| 프로젝트 산출물 제출 | Use Case에서 제외 |
| 진행 데이터 저장/불러오기 | UC-01, UC-05에 통합 |
| 게임 루프의 시간 흐름 | Actor로 두지 않고 Sequence Diagram의 내부 반복 흐름으로 처리 |
| 육지 장애물 회피 | UC-05 캐릭터 이동 중 발생하는 스테이지 판정으로 처리 |
| 호수 구간 이동 | UC-05 캐릭터 이동 중 발생하는 스테이지 판정으로 처리 |
| 호수 진입 가능 여부 | 호수 칸 자체는 진입 가능한 지형으로 두고, 자라가 없는 호수 위에 있는지는 Stage 판정으로 처리 |
| 실시간 상태 확인 | UC-05의 시스템 출력 및 FR-21로 처리 |
| 사운드 피드백 경험 | UC-05의 시스템 출력 및 FR-22, FR-23으로 처리 |
| 게임 리소스 표시 | 각 화면과 게임 화면의 출력 및 FR-24로 처리 |
| 전체 엔딩 화면 | 과제 필수 요구사항이 아니므로 보류 |
| 방패 아이템 | 선택 기능 |
| 건구스 커스터마이징 | 선택 기능 또는 가산 가능 기능 |
| 건구스 헤엄 기능 | 보류 기능 |
