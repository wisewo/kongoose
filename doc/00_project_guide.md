## 1. 과제 개요

최근 생성형 AI(ChatGPT, Claude, GitHub Copilot 등)는 소프트웨어 개발의 표준 도구가 되었다. 본 과제는 단순히 "동작하는 게임"을 만드는 데 그치지 않고, 학생이 스스로 문제를 정의하고 AI를 "동료 개발자(pair programmer)"로 활용하여 명확한 산출물로 이어가는 협업 과정을 체득하는 것을 핵심으로 한다.

### 학습 목표

- Python 의 함수·클래스·모듈 구조를 활용해 500~1,500 줄 규모의 프로그램을 설계·구현한다.
- Tkinter, Pygame 등 GUI 라이브러리로 이벤트 기반 프로그램의 흐름을 이해하고 구현한다.
- 생성형 AI 에 효과적으로 지시(prompting)하고, 산출 코드를 비판적으로 검토·수정·통합한다.
- 팀원 간 역할 분담, Git 버전 관리, 코드 리뷰 등 실무 협업 절차를 경험한다.

## 2. 과제 요구사항

### 2.1 게임 주제

주제는 자유 선택. 단, "기존 상용 게임의 단순 복제"는 불허하며, 클래식 게임을 모티프로 삼는 경우에도 최소 한 가지의 독자적 변형 요소(룰 변경, 신규 모드, 스토리, AI NPC, 데이터 시각화 등)를 포함해야 한다. 추천 카테고리: 퍼즐(테트리스/마인스위퍼 변형), 아케이드(벽돌깨기·스네이크·슈팅), 보드·카드(오목·체스·카드 매칭), 교육형(단어·수학·타자), 시뮬레이션(농장·도시·캐릭터 육성).

### 2.2 기능 요구사항

#### 필수 (모두 충족)

- GUI 윈도우 기반 실행 + 시작 → 진행 → 종료/결과 화면의 명확한 전환.
- 점수·시간·라이프 등 게임 상태의 실시간 표시, 키보드/마우스 이벤트 처리, 사운드 1 종 이상.
- 게임 데이터(최고 점수·사용자 설정 등)의 파일 저장·불러오기.
- 최소 1 개 이상의 사용자 정의 클래스를 활용한 객체지향 설계.

#### 가산 (선택, 가점 사유)

- 난이도 조절·멀티 스테이지·캐릭터 커스터마이즈, 2 인 대전 또는 AI 상대, 외부 라이브러리 활용.

### 2.3 기술 스택 · AI 활용 가이드라인

- Python 3.10+, GUI 는 Tkinter / Pygame / PyQt 중 택 1, Git 필수.
- 최종 보고서에 "AI 활용 로그"(사용 도구, 대표 프롬프트 5 개 이상, AI 답변을 어떻게 수정·보완했는지) 필수 포함.
