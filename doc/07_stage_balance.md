# 짧은 스테이지 밸런스 설계

## 목적

이 문서는 Pygame 기반 격자형 게임의 초기 스테이지 밸런스 기준을 정의한다.
이 프로젝트는 과제용이므로 각 스테이지는 짧고, 이해하기 쉽고, 설명하기 쉬워야
한다. 첫 구현에서는 무작위 맵 생성 대신 4개의 고정 스테이지를 사용한다.

목표는 조작법을 이해한 플레이어가 각 스테이지를 약 45초에서 90초 안에 클리어할
수 있게 만드는 것이다. 초기 짧은 맵보다 세로 길이를 약 3배로 늘렸기 때문에,
카메라는 플레이어를 따라가며 화면에는 큰 타일을 유지한다.

## 선택한 접근 방식

4개의 짧은 고정 퍼즐형 스테이지를 사용한다.

이 방식은 구현 범위를 작게 유지하고, 난이도 조절을 쉽게 하며, 다음과 같은 명확한
진행 구조를 제공한다.

1. Stage 1은 이동과 목적지 도착을 학습시킨다.
2. Stage 2는 자전거 장애물을 소개한다.
3. Stage 3은 강 타일과 거북이 발판을 소개한다.
4. Stage 4는 앞에서 학습한 요소들을 조합한다.

무작위 맵 생성은 첫 버전에서 제외한다. 무작위 맵은 밸런싱, 테스트, 설명을 더
어렵게 만들기 때문이다.

## 스테이지 기본값

이 문서에서 맵 크기는 열 x 행으로 표기한다. 구현에서는 같은 값을 `TerrainMap`의
rows와 columns로 저장할 수 있다.

| 스테이지 | 주요 목표 | 맵 크기 | 주요 요소 | 3성 | 2성 | 1성 |
|---|---|---:|---|---:|---:|---:|
| Stage 1 | 이동과 목적지 도착 학습 | 7x21 | 벽 9-13개 | 45초 | 68초 | 100초 |
| Stage 2 | 자전거 회피 | 8x21 | 벽 12-17개, 자전거 후보 행 8개 | 55초 | 83초 | 120초 |
| Stage 3 | 거북이를 이용한 강 통과 | 9x21 | 강 타일 27칸, 거북이 3개 | 65초 | 98초 | 145초 |
| Stage 4 | 종합 난이도 | 10x24 | 벽 18-27개, 자전거 후보 행 8개, 학생 무리 1개, 거북이 3개 | 80초 | 120초 | 175초 |

이 수치는 시작 기준이다. 실제 플레이 테스트 후 조정한다.

## 맵 설계 규칙

각 스테이지에는 START에서 GOAL까지 이어지는 명확한 의도 경로가 있어야 한다.
다만 회피하거나 기다릴 수 있는 작은 여유 공간도 함께 둔다.

최소 이동 경로 길이는 짧게 유지한다.

| 스테이지 | 목표 최소 경로 길이 |
|---|---:|
| Stage 1 | 24-32칸 이동 |
| Stage 2 | 22-32칸 이동 |
| Stage 3 | 20-32칸 이동 |
| Stage 4 | 25-40칸 이동 |

벽은 단순히 공간을 채우기 위한 요소가 아니라 플레이어의 이동 방향을 유도하는
요소로 사용한다. 긴 맵 버전에서는 세로 이동 흐름이 끊기지 않도록 벽 밀도를
전체 맵의 약 7-13% 안에서 유지한다.

각 스테이지의 START는 가장 아래 행의 중앙에 둔다. GOAL은 가장 위 행의 중앙에
두어 플레이어가 화면 위쪽으로 진행해야 한다는 방향 힌트를 준다.

움직이는 장애물은 플레이어가 규칙을 익힌 뒤에는 더 자주 마주치도록 배치한다.

1. Stage 1에는 움직이는 장애물을 배치하지 않는다.
2. Stage 2에는 벽이 없는 행에 자전거 후보 행 8개를 배치한다.
3. Stage 3에는 강 행마다 거북이 발판 1개씩, 총 3개를 배치하고 자전거는 배치하지 않는다.
4. Stage 4에는 벽이 없는 행에 자전거 후보 행 8개, 학생 무리 이벤트 1개, 거북이 발판 3개를 배치한다.

자전거는 `bike_lane` 단위로 관리한다. 각 자전거 행은 방향, 속도, 스폰 간격,
초기 오프셋, 최대 동시 등장 수를 따로 가지며, 여러 행이 동시에 자전거를
등장시킬 수 있다. 같은 행에서도 스폰 간격이 충분히 짧으면 여러 대가 동시에
지나갈 수 있다.
자전거 벨은 특정 자전거의 경고음이나 등장 신호가 아니라, 자전거 후보가 있는
스테이지에서 배경 효과음처럼 비주기적으로 재생된다. 한 번 재생될 때 1-3번
울릴 수 있고, 각 재생 볼륨은 무작위다. 플레이어는 실제 화면에 나타난 자전거를
보고 즉시 피해야 한다.
자전거는 기존보다 더 느리게 움직여 플레이어가 화면에서 보고 피할 시간을 준다.
Stage 2의 기본 속도는 4.8-5.2 tiles/s, Stage 4의 기본 속도는 5.8-6.2 tiles/s
범위로 두며, 한 행을 약 1.2-1.8초에 가로지르는 범위를 목표로 한다.
자전거 후보 행에는 벽을 두지 않는다. 거북이는 이전 짧은 맵 기준보다
약 2배 이상 빠르게 움직인다.

강은 `RIVER` 지형으로 부른다. 강 행은 맵의 왼쪽 끝부터 오른쪽 끝까지 끊기지
않아야 하며, 두 줄 이상 연속해서 배치하지 않는다. 강을 여러 줄 배치할 때는
사이에 일반 이동 행을 하나 이상 둔다.
강물 환경음은 강 지형이 있는 Stage 3과 Stage 4에서만 반복 재생하고, 실패,
클리어, 스테이지 선택, 메인 화면으로 전환할 때 정지한다.

학생 무리는 첫 버전에서 Stage 4에만 등장시킨다. 학생 무리는 넓은 영역에 영향을
주므로 작은 맵에서는 쉽게 불공정하게 느껴질 수 있기 때문이다.
학생 무리 경고는 시각 경고를 기본으로 사용하고, 학생 무리 사운드는 실제 등장
순간을 알리는 효과음으로 한 번 재생한다. 현재 값은 경고 시간 1.0초, 등장 시간
4.17초다.
학생 무리의 실제 등장 유지 시간은 적용된 음원 길이에서 경고 1초를 뺀 값으로 두고, 화면 렌더링에서 가로 이동하는
속도만 기존보다 3배 빠르게 표현한다. 등장 시간이 끝난 뒤에는 새 러너를 더
보충하지 않고, 이미 보이는 러너만 오른쪽으로 빠져나가게 표현한다.

## 별점 규칙

기본 별점 기준은 짧은 스테이지 목표에 맞춰 정한다.

1. 3성: 거의 기다리지 않고 깔끔하게 클리어했을 때의 시간
2. 2성: 3성 기준 시간의 약 1.5배
3. 1성: 3성 기준 시간의 약 2.2배

1성 기준 시간을 넘겨도 스테이지 클리어는 가능하다. 별점은 클리어 성과를 기록하기
위한 기준으로만 사용한다.

## 조정 규칙

구현 후에는 간단한 플레이 테스트 관찰을 기준으로 수치를 조정한다.

1. 처음 플레이하는 사람이 규칙을 이해하기 전에 자주 실패한다면 장애물 수를
   줄이거나 안전 공간을 늘린다.
2. 실수 없는 클리어가 40초를 넘는다면 경로를 줄이거나 대기 시간을 줄인다.
3. 플레이어가 장애물을 무시하고 지나갈 수 있다면 장애물을 의도 경로에 더 가깝게
   옮긴다.
4. 스테이지가 불공정하게 느껴진다면 시간을 먼저 늘리기보다 안전 타일을 하나
   추가한다.
5. 3성을 받기 위해 완벽한 타이밍이 필요하다면 3성 기준 시간을 3-5초 늘린다.

## 구현 메모

스테이지 데이터는 코드에 직접 쓰지 않고 `data/stages/` 아래 파일로 분리한다.
각 스테이지 맵은 `stage_1_map.txt`처럼 텍스트 파일 하나로 표현하고, 자전거,
학생 무리, 자라 같은 동적 객체 배치는 `actors.csv`에 모아 둔다.

지형 모델은 기존 문서에 정의된 개념을 그대로 사용한다.

- LAND
- RIVER
- SAFE
- WALL
- START
- GOAL

자전거, 학생 무리, 거북이 같은 스테이지별 객체는 정적 지형과 분리해서 설정한다.
이렇게 하면 맵 배치와 움직임 규칙을 서로 독립적으로 조정하기 쉽다.

스테이지를 시작하거나 재시작할 때 플레이어와 동적 객체는 최초 배치 상태로
초기화한다. 자전거는 `actors.csv`의 `bike_lane` 행을 스폰 규칙으로 사용하며,
각 lane의 `spawn_gap`과 `initial_offset`에 따라 비활성 자전거 풀에서 한 대씩
활성화한다. 자전거 사운드는 이 스폰 타이밍과 묶지 않고 `Game`이 자전거가 있는
스테이지에서 비주기적 ambience로 관리한다. 강물 사운드도 `Game`이 현재 스테이지의
`RIVER` 지형 여부를 보고 반복 재생과 정지를 관리한다.
화면 밖으로 나간 자전거는 다시 비활성화된다. 거북이는 한 칸짜리 이동 발판으로 맵 너비 안에서
순환한다. 자전거와 거북이의 판정은 격자 좌표를 유지하되, 렌더링에서는 이동
진행률을 픽셀 오프셋으로 반영해 부드럽게 움직이는 것처럼 표현한다.

## 제외 범위

첫 밸런스 버전에는 다음 기능을 포함하지 않는다.

- 무작위 맵 생성
- 4개를 초과하는 스테이지
- 방패 또는 아이템 기능
- 캐릭터 커스터마이징
- 플레이 중 동적으로 변하는 별점 기준

이 기능들은 고정 4스테이지 버전이 완성된 뒤에 고려한다.

Bike ambience behavior note: the bike bell cue is ambient on stages with bikes.
It is not tied to a specific warning row or spawn frame.

Turtle behavior note: turtles are one-tile moving platforms. The first version
does not support multi-tile turtles or moving within a turtle body.

Star display note: star ratings should render with star image assets when the
assets are available. Text stars are only a fallback for missing images.
