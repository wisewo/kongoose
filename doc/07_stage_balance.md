# 스테이지 밸런스 설계

## 목적

이 문서는 고정 4스테이지 버전의 실제 맵 길이, 지형 배치, 장애물 배치를
정리한다. 첫 구현은 팀 프로젝트에서 설명하고 테스트하기 쉬워야 하므로 무작위 맵
생성이나 추가 스테이지는 포함하지 않는다.

이번 최종 조정의 핵심은 스테이지별 컨셉을 분리하는 것이다. Stage 2는 장애물과
자전거만 다루고, Stage 3은 강과 자라만 다룬다. Stage 4는 앞의 요소를 모두 섞은
종합 맵이다. 길이는 `Stage 1 < Stage 2 = Stage 3 < Stage 4`를 유지한다.

## 진행 흐름

| 스테이지 | 학습 목표 | 핵심 요소 |
|---|---|---|
| Stage 1 | 기본 이동과 목적지 도착 | 짧은 길이, 벽으로 경로 유도 |
| Stage 2 | 육지 장애물 회피 | 다양한 벽 장애물, 다양한 속도의 자전거 행 |
| Stage 3 | 강 건너기 | 1~8행 길이의 강 구간, 2~4개 연속 자라 발판 |
| Stage 4 | 종합 난이도 | 벽, 자전거, 강, 자라, 2줄 이상의 학생 무리 |

Stage 1은 기존보다 약 절반 길이로 줄여 튜토리얼 성격을 강화한다. Stage 2와
Stage 3은 같은 길이지만 전혀 다른 위험 요소를 다루도록 분리한다. Stage 4는 가장
길고, 앞에서 배운 모든 판정을 한 맵에서 다시 확인하게 한다.

## 기준값

맵 크기는 `열 x 행`으로 표기한다. 행 번호는 `data/stages/stage_*_map.txt`의
위쪽을 0으로 보는 구현 기준이다.

| 스테이지 | 맵 크기 | 배치 기준 | 3성 | 2성 |
|---|---:|---|---:|---:|
| Stage 1 | 7x21 | 벽 14개, 동적 장애물 없음 | 40초 | 60초 |
| Stage 2 | 8x35 | 벽 15개, 자전거 8행/16대, 강과 자라 없음 | 75초 | 113초 |
| Stage 3 | 9x35 | 강 18행, 자라 54개, 강 길이 1/2/3/4/8행 | 75초 | 113초 |
| Stage 4 | 10x43 | 벽 12개, 자전거 8행/16대, 강 14행, 자라 43개, 학생 무리 3행 | 100초 | 150초 |

별점은 클리어 성과 기록용이며 실패 조건이 아니다. 3성 기준 이내면 3성, 2성 기준
이내면 2성, 그보다 오래 걸리면 1성으로 기록한다.

## 맵 규칙

- START는 가장 아래 행 중앙, GOAL은 가장 위 행 중앙에 둔다.
- START에서 GOAL까지 명확한 의도 경로가 있어야 한다.
- 벽은 막기 위한 장식이 아니라 이동 방향과 대기 위치를 유도하는 장애물로 둔다.
- Stage 1에는 움직이는 장애물, 강, 자라, 학생 무리를 두지 않는다.
- Stage 2에는 강과 자라를 두지 않는다.
- 자전거 행에는 벽과 강을 두지 않아 움직임과 충돌 판정이 명확하게 보이도록 한다.
- 강 행은 맵의 좌우를 끊기지 않고 전폭 RIVER로 가로지른다.
- 자라가 있는 강 행의 위아래가 다른 자라 행이 아니라면, 해당 이웃 행은 전폭
  LAND 하차 행이어야 한다. START 또는 GOAL은 그 하차 행 안의 한 칸으로만 허용한다.
- 학생 무리는 Stage 4에서만 사용하며, 최소 2행 이상 배치한다.

## Stage 1 배치

Stage 1은 7열 21행이다. 기존 39행 튜토리얼을 약 절반으로 줄여 플레이어가 기본
상하좌우 이동과 벽 우회를 빠르게 익히도록 한다.

- START: row 20, column 3
- GOAL: row 0, column 3
- 벽: 14개
- 동적 객체: 없음

## Stage 2 배치

Stage 2는 8열 35행의 육지 맵이다. 컨셉은 장애물과 자전거이므로 강, 자라, 학생
무리를 모두 제거한다. 벽은 일반 이동 장애물로 쓰고, 자전거 행은 전폭 LAND로
비워서 속도와 방향을 읽기 쉽게 한다. 벽 수를 줄인 대신 자전거 행을 늘려 Stage 2의
핵심 위협을 자전거 회피로 잡는다.

| row | 방향 | 속도 | 초기 column |
|---:|---|---:|---|
| 5 | right | 4.6 | 1, 2 |
| 9 | left | 3.8 | 0, 1 |
| 10 | right | 3.8 | 4, 5 |
| 13 | left | 3.0 | 1, 2 |
| 14 | right | 3.0 | 4, 5 |
| 15 | right | 3.0 | 6, 7 |
| 23 | left | 3.8 | 2, 3 |
| 24 | right | 3.8 | 6, 7 |

row 9-10과 row 23-24는 두 자전거 행이 연달아 나오는 구간이므로 밴드 전체를 같은
속도 3.8로 맞춘다. row 13-15는 세 자전거 행이 연달아 나오는 구간이므로 밴드
전체를 같은 속도 3.0으로 맞춘다. 단독 자전거 행은 row 5만 남겨 패턴을 단순화하고,
2개 이상 연속된 자전거 행은 한 밴드 안에서 같은 속도를 사용한다. 연속 행 수가
길어질수록 단독 행보다 속도를 크게 낮춘다. 같은 행의 두 자전거는 붙은 묶음으로
지나가게 두어, 묶음이 지나간 뒤 긴 빈틈이 생기도록 한다. 연속 행 밴드에서는
묶음의 시작 column을 row마다 어긋나게 배치해 인접 행 자전거가 동시에 달리는
느낌을 줄인다. 자전거는 같은 행 안에서 같은 방향과 속도로 움직이며, 화면 끝을
지나면 반대편으로 순환한다.
스테이지 시작과 재시작 때는 단독 row 또는 연속 row 밴드별로 시작 column offset을
랜덤 적용해, 밴드 내부의 row 간 어긋남은 유지하면서 매번 회피 타이밍이 달라지게
한다.

## Stage 3 배치

Stage 3은 9열 35행의 강/자라 전용 맵이다. 강 길이는 1행부터 8행까지 다양하게
두어, 짧은 단발 강과 긴 연속 강을 모두 경험하게 한다.

| 강 row | 길이 | 자라 배치 원칙 |
|---|---:|---|
| 2 | 1행 | 3개 연속 |
| 6-7 | 2행 | 행마다 2-3개 연속 |
| 11-14 | 4행 | 행마다 2-4개 연속 |
| 18-25 | 8행 | 행마다 2-4개 연속 |
| 29-31 | 3행 | 행마다 2-4개 연속 |

모든 자라 행은 한 행 안에서 같은 방향과 속도를 사용한다. 자라는 2~4개가 붙은
묶음으로 시작해, 너무 듬성듬성하거나 지나치게 빽빽하지 않은 리듬을 만든다.

## Stage 4 배치

Stage 4는 10열 43행의 종합 맵이다. 벽, 자전거, 강, 자라, 학생 무리를 모두 포함해
최종 확인용 난이도를 만든다. 학생 무리는 3개 행에 배치해 요구 조건인 2줄 이상을
충족한다.

| 요소 | row |
|---|---|
| 자전거 | 1, 2, 12, 13, 37, 38, 39, 40 |
| 학생 무리 | 4, 14, 24 |
| 강 구간 | 8-10, 16-20, 26-27, 32-35 |

Stage 4의 자전거는 모두 2개 이상 연속된 행으로 배치한다. row 1-2와 row 12-13은
두 자전거 행이 연달아 나오는 구간이므로 밴드 전체를 같은 속도 4.0으로 맞춘다.
row 37-40은 네 자전거 행이 연달아 나오는 구간이므로 밴드 전체를 같은 속도
2.6으로 맞춘다. 같은 행의 두 자전거는 붙은 묶음으로 배치하고, 연속 행 안에서는
묶음 시작 column을 서로 어긋나게 둔다. Stage 4의 4연속 밴드는 2연속 밴드보다 더
긴 연속 구간이므로 더 낮은 속도를 사용한다. 자라는 Stage 3과 같은 2~4개 연속
묶음 규칙을 유지한다.
학생 무리는 한 줄 전체를 위협하는 장애물이며, 등장 전 시각 경고를 제공하고 같은
경고/등장 주기를 반복한다.

## 장애물 기준

자전거는 Stage 2와 Stage 4의 주요 육지 위험 요소다. 별도 스폰 시스템을 두지 않고
`actors.csv`에 기준 위치를 고정한 뒤, 스테이지 초기화 때 단독 row 또는 연속 row
밴드별 랜덤 offset을 더해 시작 타이밍을 바꾼다. 같은 행의 자전거는 direction과
speed를 통일한다.
2개 이상 연속된 자전거 행은 같은 밴드 안에서 speed를 통일하고, 연속 행 수가
길어질수록 speed를 크게 낮춘다. 이번 배치에서는 2연속 밴드는 3.8~4.0, 3연속
밴드는 3.0, 4연속 밴드는 2.6을 사용한다.
같은 행의 두 자전거는 붙은 묶음으로 두고, 연속 행 밴드 내부에서는 묶음 시작
column을 어긋나게 배치한다.

자라는 한 칸짜리 이동 발판이다. 플레이어가 강 위에서 자라 없이 있거나, 자라에 탄
채 화면 밖으로 밀려나면 실패한다. 자라 탑승, 자라 간 이동, LAND 하차는 화면에
보이는 자라 위치와 맞추기 위해 이동 진행률 50% 전에는 현재 칸, 50%부터는 다음 칸을
기준으로 판정한다.

학생 무리는 한 줄 전체를 채우는 특수 장애물이다. Stage 4에만 사용하며, 이번
배치에서는 3행을 같은 경고/등장 주기로 반복한다.

## 구현 메모

스테이지 데이터는 `data/stages/` 아래 파일로 분리한다. 맵은
`stage_1_map.txt` 같은 텍스트 파일로, 자전거/학생 무리/자라는 `actors.csv`로
관리한다.

지형 표기는 다음 문자를 사용한다.

- `.`: LAND
- `~`: RIVER
- `-`: SAFE
- `#`: WALL
- `S`: START
- `G`: GOAL
- `B`: BOAT

현재 고정 4스테이지에서는 `BOAT`를 사용하지 않는다. 환경음은 고정 스테이지 전제에
맞춰 Stage 2는 자전거, Stage 3은 강물, Stage 4는 자전거와 강물을 반복 재생한다.

## 제외 범위

첫 밸런스 버전에는 다음 기능을 포함하지 않는다.

- 무작위 맵 생성
- 4개를 초과하는 스테이지
- 방패 또는 아이템 기능
- 캐릭터 커스터마이징
- 플레이 중 동적으로 변하는 별점 기준
